# Archive

Completed migration history belongs here — material that is fully superseded
but kept so past decisions stay traceable.

Nothing is archived yet: `performance/reports/` holds dated evidence that
stays addressable (not archive), and the moved design notes under
`architecture/`, `performance/`, and `proposals/` are still live inputs.

When archiving, move the file with `git mv`, leave no stub, and record the
superseding document and revision in the archive note's header.

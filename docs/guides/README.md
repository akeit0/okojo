# Guides

Contributor-facing workflows. These describe how to do a task, not what the
engine currently does.

- [OKOJO_PACKABLE_PACKAGE_WORKFLOW.md](OKOJO_PACKABLE_PACKAGE_WORKFLOW.md) —
  versioning, internal references, and publishing for split packages.
- [OKOJO_FEATURE_NOTE_TEMPLATE.md](OKOJO_FEATURE_NOTE_TEMPLATE.md) — required
  shape of a feature kickoff note (required by `AGENTS.md`).
- [FEATURE_IMPLEMENTATION_WORKFLOW.md](FEATURE_IMPLEMENTATION_WORKFLOW.md) —
  the implementation loop a feature note must follow.
- Host/tool debugging workflows live with their integration:
  [`../integrations/node/OKOJO_NODE_INK_DEBUG_WORKFLOW.md`](../integrations/node/OKOJO_NODE_INK_DEBUG_WORKFLOW.md).
